# WB Mesh — пульт логиста городской доставки

[README](../README.md) · [Как считается модель](technical.md)

## Для кого

**Основной пользователь — логист городской доставки WB**: сотрудник СЦ, который планирует смену машин между СЦ и ПВЗ города.

| Сейчас | С пультом WB Mesh |
|---|---|
| Каждая партия по умолчанию едет через СЦ-2, даже если покупатель в соседнем районе | Система по каждой партии сама выбирает: ПВЗ-хаб по пути или СЦ-2 |
| Свободные полки и простаивающие сотрудники ПВЗ не используются | Хабы получают задание на приём заранее, место и время бронируются |
| Эффект решения не виден: нет цифр по партии и по смене | Каждая партия — с эффектом в рублях и минутах, смена — с итогом |

**Другие участники** видят результат в своих кабинетах. В MVP это вкладка «Эффект»:
- **Владелец ПВЗ** получает задания на приём, видит доход и может подключить уровень «ПВЗ-хаб».
- **Продавец** видит статус «принят в ПВЗ-хабе» и более ранний срок выдачи.
- **Покупатель** получает заказ раньше и дешевле.

## Для чего — задачи логиста

1. **Утром:** открыть смену и увидеть, сколько партий система уже распределила и какой эффект это даст.
2. **В течение смены:** решить только исключения — партии, которые система не подтверждает сама.
3. **В конце смены:** получить итог по деньгам, времени, пробегу и нагрузке хабов.
4. **Раз в неделю:** настроить тарифы и пороги, подключить новые ПВЗ-хабы, посмотреть границу выгодности.

## Что делается автоматически, а что — логистом

| Автоматически (система) | Логист |
|---|---|
| Подбор ПВЗ-хаба по пути: габарит, место, время сотрудника, загрузка, срок, выгода | Подтверждает исключения одним нажатием или отправляет партию через СЦ-2 |
| Бронь полки и времени сотрудника хаба на окно приёма | Меняет тарифы и пороги (вкладка «Деньги») |
| Задание ПВЗ на приём партии и маршрут водителю по улицам | Подключает ПВЗ с уровнем «хаб» |
| Возврат партии на СЦ-2 или сдвиг отправки на 15–30 мин при перегрузке | Разбирает инциденты: возвраты и пересорты из журнала |
| Расчёт эффекта по каждой партии и за смену | Смотрит итоги и аналитику |

**Правило исключения.** Партию на подтверждение логисту система выносит, если:
- выгода через хаб меньше 100 ₽ на партию;
- срок через хаб хуже СЦ-2 больше чем на 10 мин;
- хаб недоступен по причине, отличной от «СЦ-2 выгоднее»: перегрузка, место, габарит без согласия.

Одинаковые исключения сводятся в одну карточку («8 партий: загрузка выше 80% → подтвердить все»).

## Требования

### Функциональные

| № | Требование | В MVP |
|---|---|---|
| Ф1 | Для каждой партии выбирать путь (хаб или СЦ-2) по ограничениям и экономике | ✅ |
| Ф2 | Бронировать место и время сотрудника хаба, учитывать брони следующих партий | ✅ |
| Ф3 | Показывать логисту очередь партий смены: время, машина, путь, эффект, статус | ✅ Пульт |
| Ф4 | Выносить исключения на подтверждение, группировать одинаковые | ✅ (решение фиксируется в журнале пульта) |
| Ф5 | Считать эффект партии и смены: ₽, минуты, км, нагрузка хабов | ✅ |
| Ф6 | Поддерживать возвраты, пересорты, хранение у продавца | ✅ |
| Ф7 | Давать владельцу ПВЗ подключить уровень «хаб» с выделенной зоной | ✅ модель и экран |
| Ф8 | Редактировать тарифы и пороги без программиста | ✅ вкладка «Деньги» |
| Ф9 | Отправлять задание в ПВЗ и маршрут водителю | Пилот: через API учётных систем |

### Нефункциональные

| Требование | Значение | В MVP |
|---|---|---|
| Время решения по партии | < 1 с | ≈ 8 мс на маршрут, миллисекунды на выбор хаба |
| Работа без интернета | Расчёт не останавливается | Офлайн-граф улиц, офлайн-карта, оценки при сбоях |
| Понятность | Логист без обучения понимает решение | Чек-лист причин, эффект в ₽ и мин у каждой партии |
| Прозрачность | Каждая цифра объяснима формулой | Вкладка «Деньги» → «Как считается выгода» |
| Масштаб | Город на 100–1 300 ПВЗ | Йошкар-Ола 145, Чебоксары 264, Москва 1 286 ПВЗ в справочнике |

### Интеграции для пилота

| Источник | Что нужно | Зачем |
|---|---|---|
| Учётная система ПВЗ | Фактическая загрузка полок по часам, график сотрудников | Заменить модельную загрузку на реальную |
| Диспетчерская система СЦ | Партии и машины смены | Входная очередь вместо генератора спроса |
| Приложение водителя | Маршрут и точки сканирования | Исполнение решения и контроль передач |
| Финансовая система | Ставки перевозчика, СЦ, выплаты ПВЗ | Калибровка экономики |

## Дорожная карта

1. **Пилот, 6 недель.** 3–5 ПВЗ-хабов в Йошкар-Оле, A/B на партиях, метрики из README.
2. **Город целиком.** Все коридоры, планирование смены целиком вместо жадного выбора по партии.
3. **Межгород.** Коридоры Москва → Казань → Чебоксары → Йошкар-Ола: магистраль сдаёт партию в хаб на въезде в город.
